# Finance merchant marks

Finance displays these locally stored marks for linked organizations whose website matches an official domain. The files came from the merchants or their parent companies on November 4, 2026.

- [7 Brew](https://7brew.com/) publishes the transparent 7B monogram as its [touch icon](https://7brew.com/icons/apple-touch-icon.png). The local PNG preserves the source pixels and trims transparent margins.
- [Allstate](https://www.allstate.com/) serves its blue A as an [SVG site icon](https://www.allstate.com/favicon.ico).
- [Canva’s brand guidelines](https://www.canva.dev/docs/apps/rest-apis/brand-guidelines/) specify the icon for surfaces below 50px. The local copy is `Canva logos/svg/Canva Icon logo.svg` from the [official logo pack](https://www.canva.dev/assets/connect/Canva-logos.zip).
- [Inspire Brands](https://inspirebrands.com/jimmy-johns-logo/) supplies the [red Jimmy John’s monogram](https://inspirebrands.com/wp-content/uploads/2023/10/JJ-Red-2.png).
