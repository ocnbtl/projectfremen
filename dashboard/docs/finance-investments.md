# Personal Plaid Investments

Finance → Accounts → Connections → **Connect investments** opens a dedicated Plaid Investments session. Choose Vanguard (or another supported investment institution), sign in inside Plaid/the institution, grant account access, then review the suggested Finance matches and **Save matches & sync**. A unique existing account with the same institution and mask is suggested; ambiguous accounts require selection. Retirement accounts use Finance's Brokerage kind. Existing account names and annotations are preserved.

This uses the existing Plaid Trial credentials, registered accounts redirect, encrypted store and signed webhook endpoint. No migration, extra secret or paid upgrade is required. Bank and Investments connections share ten lifetime Trial Items; deleting an Item does not replenish the allowance. Existing Items reconnect in update mode. Eligibility still depends on Plaid's support for the selected institution and accounts.

The server requests `products: ["investments"]` and investment account subtypes `all`. It fetches `/investments/holdings/get` and up to 90 days of `/investments/transactions/get`, with 500 entries per page and a 5,000-entry cap. Activity remains separate from the spending ledger. Account balances are authoritative and holdings are not added to them again. USD investment accounts are supported. Unknown balances preserve the prior dated balance; missing cost basis and price dates remain unknown.

Holdings/activity snapshots and access tokens use the existing authenticated encryption and durable CAS storage. The public authenticated DTO excludes credentials, Item IDs and Link sessions. The mutation route retains authentication, CSRF, bounded bodies and private/no-store responses. Provider errors are sanitized. The investment transaction request permits up to 120 seconds for initial history, within a bounded 210-second retrieval window. Complete validation precedes Finance balance writes; a partial page, changing total, duplicate ID or unsupported data preserves the previous snapshot. `PRODUCT_NOT_READY` for history saves available holdings while retaining earlier activity and its original dates.

Verified signed `HOLDINGS/DEFAULT_UPDATE` and `INVESTMENTS_TRANSACTIONS/DEFAULT_UPDATE` notifications retrieve available snapshots. Existing Item attention notifications trigger reconnect. Updates depend on the institution, typically daily on market days; Sync now retrieves currently available Plaid data and does not promise live market prices or invoke the optional Investments Refresh endpoint. Disconnect revokes the Item, erases its credentials and preserves the last saved snapshot and Finance records.

Run `npm run test:finance-investments`, `test:finance-banking`, `test:finance-coinbase`, `test:finance-redesign`, `typecheck`, `build` and `regress`. Harnesses use isolated local fixtures and mocked providers and consume no Trial slots.
